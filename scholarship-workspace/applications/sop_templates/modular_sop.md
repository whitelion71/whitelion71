# Modular SOP Framework

> Build each tailored SOP by assembling: **Hook → Foundation → Bridge → Focus Module → Why This Program → Return to KSA**.
> Every SOP must name real labs, faculty and modules at the target school (Rule 4). No generic SOPs.

## A. Hook (pick one, 2–3 sentences)
- **Incident hook:** a real network outage or security event you handled, and what it showed you.
- **Scale hook:** the size of the infrastructure you've operated (sites, subscribers, traffic).

## B. Foundation — Telecom Operations (≈150 words)
Hands-on RF / VoLTE / NOC experience, with quantified results from `projects_portfolio.md`.

## C. Bridge — Automation & Applied AI (≈150 words)
RAG systems and AI agents you built, and what they changed in operations or governance.

## D. Focus Module (choose ONE per program)
- **D1 — AI-driven Network Security:** anomaly and intrusion detection in 5G core/RAN, adversarial robustness.
- **D2 — Next-Gen Networks (5G/6G):** network slicing, Open RAN security, intent-based automation.
- **D3 — Critical Infrastructure Protection:** OT/ICS, resilience, zero-trust, security governance (NCA frameworks).
- **D4 — Applied AI / Agents:** LLM agents for autonomous network operations, trustworthy AI.

## E. Why This Program (≈200 words — fully tailored)
- 2–3 named modules · 1–2 named faculty/labs and why · a capstone or project opportunity · the 1-year format (UK) or research depth (US).

## F. Return to KSA & Vision 2030 (≈100 words)
Which entity or sector you'll serve, and the specific capability you'll bring back.

**Length targets:** UK personal statement ≈ 600–1,000 words / 4,000 characters (VERIFY per school); US SOP ≈ 1–2 pages.
