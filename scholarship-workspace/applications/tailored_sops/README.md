# Tailored SOPs

Naming: `<university-or-entity>_<program>_v<N>.md` (e.g., `surrey_msc5g_v1.md`, `nca_waed_2027_v1.md`).

Each file starts with a research block:
- Program URL and last-verified date
- 2–3 modules referenced
- 1–2 faculty/labs referenced
- Portfolio projects used (from `profile/projects_portfolio.md`)
- Focus module chosen (D1–D4)
